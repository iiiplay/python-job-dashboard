# Python 工程師市場分析儀表板

單頁互動式資料視覺化儀表板，基於 104 人力銀行 1,600+ 筆 Python 工程師職缺樣本，呈現地區分佈、薪資區間、技能需求、產業分佈、作品方向與學習路線的全方位市場洞察。整份成品為**單一 HTML 檔**，深色科技風、雙擊即開，適合作為求職準備與市場了解的參考。

## 功能特色

- **總覽 KPI**：職缺樣本數、地區、薪資區間、技能項目等關鍵數字卡片。
- **地區分佈**：全台北中南職缺數量與佔比分析。
- **薪資分析**：不同區間、條件下的薪資解析。
- **技能需求**：涵蓋 73 項技能的需求統計與排行。
- **產業分佈**：招募 Python 工程師的產業結構。
- **作品方向**：面向求職的作品集（portfolio）方向建議與技能標籤。
- **學習路線**：從入門到就業的階段式 roadmap。
- **導覽與互動**：sticky 導覽列錨點跳轉、卡片 hover 動效、Chart.js 圖表與資料標籤，並支援 600px 以下的響應式版面。

> 資料說明：分析僅供參考，實際薪資依公司規模、經驗及談判能力而異（見頁尾聲明）。

## 技術棧

- 純 HTML / CSS / JavaScript（單檔、無建置系統）
- [Chart.js](https://www.chartjs.org/) 4.4 + chartjs-plugin-datalabels（透過 CDN 載入）
- CSS 變數主題化的深色 UI、CSS Grid 響應式版面

## 如何執行

直接用瀏覽器開啟 `index.html` 即可（需連網以載入 Chart.js CDN）。無需安裝相依、無需伺服器。

```bash
# 或用任意本機靜態伺服器預覽，例如：
python -m http.server 8000    # 然後開 http://localhost:8000
```

## 專案結構

```
index.html    完整儀表板（樣式、資料與圖表邏輯全內嵌於單一檔案）
```
