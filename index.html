💡 產業洞察

  • 軟體服務業是最大雇主，佔比超過 17%，涵蓋 SaaS、企業軟體、雲端服務
  • 半導體 / IC / 電子製造對 Python（自動化、測試腳本）需求快速增加
  • 金融業（銀行、證券）積極導入 AI / 量化分析，Python 需求成長明顯
  • 網際網路業需要全端 Python 能力，後端 API + 資料分析雙修更競爭
📁作品集方向建議

根據市場需求，最具求職競爭力的作品方向與技術組合

🤖

AI / LLM 應用系統

建立 LLM 驅動應用：RAG 知識庫問答、AI 客服機器人、多模態影像辨識工具，整合 API 對外提供服務。

LLMRAGLangChainPyTorchFastAPIOpenCV
💰 對應薪資：5~12萬（AI 工程師）
📊

資料工程 Pipeline

設計端對端資料管道：資料擷取、清洗、ETL 轉換到視覺化儀表板，並部署於雲端自動排程執行。

ETLAirflowSparkPostgreSQLAWS/GCPPandas
💰 對應薪資：6~10萬（資料工程師）
🌐

後端 API 服務

用 FastAPI 或 Django 打造高效能 RESTful API，結合關聯式資料庫、Redis 快取，Docker 容器化部署。

FastAPI/DjangoRESTfulMySQLDockerCI/CDAWS
💰 對應薪資：4~8萬（後端工程師）
📈

數據分析與視覺化

選取公開資料集（股市/政府/社群）做深度 EDA 分析，用 Tableau / Power BI 建立互動式商業報表。

PandasNumpyTableauPower BIMatplotlibExcel
💰 對應薪資：4~7萬（數據分析師）
🔄

自動化爬蟲系統

爬取電商/新聞/政府資料，搭配排程自動更新，存入資料庫並提供 API 查詢，加入反爬機制處理。

SeleniumPlaywrightRequestsRPAMySQLScheduler
💰 對應薪資：3.5~6萬（自動化工程師）
⚙️

DevOps / 系統自動化

建立完整 CI/CD Pipeline，包含自動測試（Pytest）、Docker 容器化、Kubernetes 部署與監控告警系統。

LinuxDockerKubernetesCI/CDGitPytest
💰 對應薪資：5~10萬（DevOps/SRE）
🧬

機器學習模型專案

完整 ML 流程：EDA → 特徵工程 → 模型訓練 → 評估 → API 部署，搭配 MLflow 實驗追蹤與模型版本管理。

Scikit-learnPyTorchTensorflowXGBoostFastAPI
💰 對應薪資：5~10萬（ML 工程師）
🏦

金融科技應用（FinTech）

量化交易回測系統、財務報告自動化分析、風控模型建置，特別適合銀行/證券業求職目標。

PandasNumpyMS SQLPower BIExcel/VBAGit
💰 對應薪資：5~15萬（量化分析師）

💡 作品集策略建議

  • 必備基本功：「資料庫操作 + API 開發 + Git 版本控制」是市場最基礎要求
  • 加分亮點：Docker 部署、CI/CD 流程、雲端部署（AWS/GCP），可往 6萬+ 談
  • AI 趨勢：2024-2025 LLM/RAG 應用需求暴增，有實作 LLM 整合的作品大幅提高競爭力
  • README 品質：GitHub 要有清楚的 README、架構圖、Demo 影片和技術選型說明
  • 深度優於廣度：準備 3~5 個深度作品，比 10 個淺薄作品更有說服力
